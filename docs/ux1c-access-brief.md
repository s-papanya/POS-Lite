# UX1c — เข้าใช้และเลือกร้าน

ordinary refinement ขาว/navy ต่อจาก UX1a/b; minimal สำหรับแม่ ไม่เปลี่ยนระบบ auth หรือสิทธิ์

THESIS: เข้าบัญชี เลือกร้าน และกลับทำงานต่อได้โดยเข้าใจผลต่อรายการค้าง
OWN-WORLD: พื้นขาว/navy ตัวหลัก18px ปุ่ม48px เมนูร้านเป็นรายการเรียบ ไม่มีภาพหรือ dependencies ใหม่
STORY: ชื่อผู้ใช้/รหัสผ่าน → เลือกร้านและอ่านสิทธิ์ → งานหน้าร้าน; เปลี่ยนร้านมีเก็บ/ทิ้ง/อยู่ต่อ
FIRST VIEWPORT: ฟอร์มกว้างพอดีบน desktop มือถือหนึ่งคอลัมน์ ร้านและ action เข้าร้านเห็นชัด
FORM: รักษา incumbent, targeted code-led refinement; ไม่ใช่ replacement world ไม่มี comp/seedใหม่
FINISH: finish review และเอกสาร artifact evidence; ordinary refinement ไม่เขียน DESIGN ใหม่

รักษา autocomplete, password input, CSRF/cookie, pending block, original identity และ sessionStorage scope
ไม่สร้างบัญชี ไม่เปลี่ยนรหัสผ่านจริง ไม่ส่งข้อมูลจริงใน fixture ไม่อ้าง Android จาก desktop browser
